# Chasy P

A lightweight, secure, and privacy-focused web chat system built with WebRTC technology, enabling direct peer-to-peer (P2P) communication without intermediate servers.

Live Demo: https://chasyp.pages.dev

## ✨ Features

* **P2P Architecture:** Uses WebRTC for direct browser-to-browser communication.
* **Privacy First:** Messages are exchanged directly between peers, ensuring high security and privacy.
* **Real-time Chat:** Instant and seamless message delivery.

## 🛠️ Development & Collaboration

This project is a collaborative creation generated and refined through cutting-edge AI technologies:

1. **Initial Codebase:** Generated by ChatGPT.
2. **Refinement & Enhancements:** Iteratively edited, optimized, and extended using **muse-spark**, **Gemini**, and **Claude**.

Through careful prompt engineering and multiple feedback loops, the AI-generated code has been successfully integrated into a cohesive 200,000-character application.
